# Excel Sales Dashboard

## Project Overview
This project presents an interactive Excel sales dashboard designed to analyze business performance, sales trends, KPIs, and customer insights.

---

## Objectives
- Analyze sales performance
- Track KPIs
- Identify top-performing products
- Monitor regional sales trends
- Support business decision-making

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- KPI Metrics
- Data Cleaning

---

## Dashboard Features
- Sales KPI Cards
- Monthly Sales Trends
- Regional Performance Analysis
- Top Products Analysis
- Interactive Filters/Slicers

---

## Business Insights
- Identified high-performing regions
- Highlighted sales growth trends
- Analyzed product performance
- Improved visibility of business KPIs

- Raw Dataset
- Cleaned Dataset
- Excel Dashboard File
