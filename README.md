Superstore Sales Dashboard (Excel)

 Project Overview

This project presents an interactive sales dashboard built in Microsoft Excel using the Superstore dataset. The dashboard provides key business insights into sales performance, profitability, customer segments, and regional performance.

 Objectives

* Analyze sales and profit performance.
* Identify top-performing regions and categories.
* Evaluate customer segment contributions.
* Present business insights through interactive visualizations.

 Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Dashboard Design
* Data Analysis

 Key Performance Indicators (KPIs)

* Total Sales: $2,297,200.86
* Total Orders: 9,994
* Total Profit: $286,397.02
* Average Order Value: $229.86

#Dashboard Visualizations

1. Sales by Region
2. Sales by Category
3. Profit by Category
4. Sales by Segment

 Key Insights

* West region generated the highest sales ($725K).
* South region generated the lowest sales ($392K).
* Technology category generated the highest sales (37% of total sales).
* Technology category produced the highest profit ($145K).
* Consumer segment contributed approximately 50% of total sales.
