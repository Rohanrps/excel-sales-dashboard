Superstore Sales Dashboard

 Project Overview

This project presents a sales dashboard built in Microsoft Excel using the Superstore dataset. The dashboard analyzes sales, profit, customer segments, and regional performance through Pivot Tables and Pivot Charts.

 Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Dashboard Design

 KPIs

* Total Sales: $2,297,200.86
* Total Orders: 9,994
* Total Profit: $286,397.02
* Average Order Value: $229.86

 Dashboard Visualizations

* Sales by Region
* Sales by Category
* Profit by Category
* Sales by Segment

 Key Insights

* West region generated the highest sales.
* South region generated the lowest sales.
* Technology generated the highest sales and profit.
* Consumer segment contributed 50% of total sales.
